## 目标与背景

QML 页面开发缺乏高保真的视觉参照：直接写 QML 需要同时解决布局、交互与视觉三件事，
迭代慢。维护者确立工作流：**先用自包含 HTML 复刻目标界面作为设计参考，再对照
迁移到 QML**——HTML 的布局/间距/层级即是 QML 的 anchors/Layout/token 映射底稿。
本任务只交付 HTML 复刻件与流程文档，QML 迁移由后续页面任务跟进。

首个复刻对象为 panta 桌面主窗口 GUI 框架，以一张桌面仿真软件主窗口截图为布局
与视觉语言参照：标题工具条（快捷图标、激活动图、全局搜索、登录与窗口控制）、
菜单栏、ribbon 启动区（启动/新功能/学习）、左侧任务面板（任务/工具/共享视图
页签与打开/新建工程入口）与输出面板、中央内嵌网页视图（**按维护者要求留空**）
与状态栏。品牌、菜单与文案全部使用 panta，不出现任何第三方品牌信息；该框架与
panta 桌面工程 UI 同构，是后续 QML 主窗口任务的直接设计底稿。

完成后的可观察行为：`ai-docs/qml-html/homepage/homepage.html` 在浏览器中渲染出
与参照截图结构、布局、配色一致的桌面框架静态页面，内嵌网页区留空；QML 文档
登记该工作流。
