## 验收标准

- [ ] 修改 QML 后自动重载，面板状态恢复，服务变量/任务不丢失且不被重复执行。
- [ ] QML 语法错误、重复 key、状态版本不符或恢复失败时旧 UI 仍可交互，候选被清理。
- [ ] 连续保存只提交有效最新 generation；重载中关闭工程或窗口不产生悬空回调。
- [ ] 真实窗口与 VTK 场景重复重载可安全重建，无持续对象/连接泄漏，记录资源和线程证据。
- [ ] 发布默认禁用文件监听；修改 C++ 仍要求重编译/重启；不宣称原生句柄保持或跨平台无闪烁。
- [ ] 代码、测试、配置和文档一致，删除废弃实现；记录真实验证并同步索引。
