## 范围与非目标

## 前置条件与待决策

核对 Qt Linguist 工具是否随锁定预编译包可用，缺失时按依赖获取规范补供给；用 qsTr/tr 英文源文本方案，不另建 JSON 权威字典。偏好先使用 Qt 设置机制，不等待完整路径运行时。

## 实施步骤

1. 盘点现有文案和 UI 错误，转换为可提取的完整英文句子，定义复数和参数示例。
2. 接入 TS 提取、QM 编译与资源打包，增加 C++ 语言服务和语言设置 UI。
3. 验证动态刷新与偏好持久化，清理失效词条和原硬编码中文 UI 文案。
