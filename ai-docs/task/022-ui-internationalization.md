## 目标与背景

统一现有 UI 的英文源文案，以 Panta DSL（`.pa`）字典支持英文与简体中文切换，界面即时刷新并记住偏好。`.pa` 是唯一权威源码；Qt `.qm` 仅是构建期生成的运行时产物。

## 范围与非目标

包含现有 QML/C++ 展示文案、`.pa` 字典 schema、TS/QM 构建转换、语言设置及缺项回退；不包含完整多语言翻译、RTL 适配或 DSL 关键字本地化。

## 前置条件与待决策

复用 034 的 `.pa` 解析、Artifact 聚合和诊断边界；语言文件使用 `kind language` 的受限声明，不允许脚本、import、网络或 shell。构建阶段将校验后的 `.pa` 快照转换为临时 TS，再用预编译 QtTools 生成 Qt `.qm`，但不提交或维护 TS 源文件。偏好先使用 Qt 设置机制，不等待完整路径运行时。

## 实施步骤

1. 盘点现有文案和 UI 错误，建立稳定的英文 message key、完整句子、占位参数和复数示例。
2. 在 `.pa` 语言域中定义英文基线与 `zh-CN` 覆盖，接入校验快照到 QM 的构建转换和资源打包，增加 C++ 语言服务与语言设置 UI。
3. 验证动态刷新、偏好持久化、缺项回退和损坏字典失败路径，清理失效词条和原硬编码中文 UI 文案。

## 预计改动

现存 qml/、native/bridge/、native/app/ 与 CMake；待创建 resources/i18n/、`.pa` 编译入口和语言服务/测试。上述新增路径/类型均为规划，以实施时实际模块归属为准。
