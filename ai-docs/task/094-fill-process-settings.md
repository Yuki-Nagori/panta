## 范围与非目标

HTML 确认后迁移 QML，包含温度、填充控制、速度 / 压力切换、保压控制、分析选项及曲线编辑。工艺设置在本任务内完成持久化，Rust 提供默认值、校验与后台清单事务，Qt 维护候选投影和窗口生命周期。其他分析序列的设置、高级参数、曲线文件导入和求解执行不在本次范围内，未实现入口禁用。HTML 仅演示交互，不写工程文件。

## 实施与存储

- `.panta` 的 `fill_settings` 按导入记录 ID 保存配置，缺少条目时采用 Rust 默认值且不标记已确认。字段名明确标注 °C、cm³/s、体积百分比、秒和压力百分比。
- 温度为有限值且不低于绝对零度；流量为有限正数；切换体积为 0–100%；曲线至少一个点、至多 4096 个点，持续时间非负，压力为 0–200%，累计时间有限。
- 弹窗打开时冻结工程身份、修订、导入记录与配置。子弹窗默认至少三行，前两行为 0 s / 100%、10 s / 100%，第三行空白；完全空白行不提交，半填行不能确认。子弹窗确认只替换父级草稿，取消不发布。
- 确认经 ViewModel 传完整 DTO，Rust 后台校验、序列化、写盘后发布新快照。材料与工艺配置共用元数据写入锁；等待期间禁止关闭确认窗口及主窗口，失败保留旧配置并允许修改或取消。
- 已保存配置再次打开时回显，任务行显示 Custom 并打勾。切换其他分析序列保留 Fill 配置，但只在 Fill 下开放该入口。
