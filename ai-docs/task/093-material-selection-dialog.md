## 目标与范围

点击 Plan tasks 的 Material Data 打开 Select Material 弹窗，布局参考用户截图，样式沿用现有 Theme。默认材料为内置 PP / 25% 矿物填充材料，界面展示材料类别与带单位的参数。

Rust 提供只读材料摘要与确认命令；确认按导入记录保存稳定材料 ID，取消不修改工程。当前只有一个默认材料；材料导入、搜索、报告、自定义目录及求解器本构接线尚不实现，相应按钮禁用。HTML 已经用户确认，QML 和 Rust 接线已实现，剩余行为验收见验证记录。

方案任务左侧的完成列反映当前配置：已确认材料显示勾，未确认时保留空位；分析序列默认 Fill 即显示勾，切换有效序列后仍保持完成状态。

评审范围包含目录与资源校验、确认目标冻结、Qt 状态绑定及通知链。材料确认已迁入 Rust 后台线程，再由 Qt 拉取结果；失败保留旧值、重复确认及迟到结果需完成行为验收。

异步确认采用 Rust 单一待提交候选：后台线程负责序列化和写盘，GUI 只启动和拉取结果；成功后才发布内存状态。写入期间拒绝工程创建、打开、保存、重命名、导入及方案修改，防止并发清单覆盖；弹窗与应用关闭等待结果，确认开始后不再接受取消。结果消费后解除提交锁，失败保留旧配置。

## 保存位置与时机

材料选择保存到当前工程的 `<工程目录>/<工程名>.panta`，实际目标由 `ProjectViewModel.currentPath` 表示。工程清单的 `materials` 字段保存导入记录 ID 到材料版本 ID 的映射，例如：

```json
{
  "materials": {
    "import-1": "pp-mineral-25-v1"
  }
}
```

点击材料弹窗的 OK 即启动后台保存；成功后更新任务行并显示完成勾，不需要再点击工程 Save。手动保存工程也将已确认的 `materials` 映射写入同一个 `.panta` 文件；材料提交进行中暂不接受工程 Save，避免并发写入。Cancel / Esc 仅在提交前放弃候选。

默认材料的实际参数位于 [`resources/materials/pp-mineral-25.json`](../../resources/materials/pp-mineral-25.json)，通过 Rust `include_str!` 编译到程序中。工程只存材料版本引用，不复制完整参数，也不在工程 `assets/` 下创建材料文件。运行时打开工程时校验引用，并从内置目录取得名称和参数摘要；当前尚不支持用户自定义材料文件。

写盘先生成同目录的 `<工程名>.panta.tmp`，成功后替换 `.panta`；临时文件不是材料资源。写盘失败保留原工程清单及已确认的内存状态。
