## 目标与范围

点击 Plan tasks 的 Material Data 打开 Select Material 弹窗，布局参考用户截图，样式沿用现有 Theme。默认材料为内置 PP / 25% 矿物填充材料，界面展示材料类别与带单位的参数。

Rust 提供只读材料摘要与确认命令；确认按导入记录保存稳定材料 ID，取消不修改工程。当前只有一个默认材料；材料导入、搜索、报告、自定义目录及求解器本构接线尚不实现，相应按钮禁用。先完成 HTML 参考的弹窗入口与布局，经用户确认后调整 QML 草稿并完成接线。

方案任务左侧的完成列反映当前配置：已确认材料显示勾，未确认时保留空位；分析序列默认 Fill 即显示勾，切换有效序列后仍保持完成状态。

评审范围包含目录与资源校验、确认目标冻结、Qt 状态绑定及通知链。确认命令当前仍同步写工程清单；需将持久化移入 Rust 后台任务，再由 Qt 接收结果，验证失败保留旧值、重复确认及迟到结果后才完成验收。
