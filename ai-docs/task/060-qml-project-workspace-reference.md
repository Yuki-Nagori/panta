- 提取共用 Ribbon 分组与横向滚动 / 键盘焦点显露逻辑；保留已有滑块页签、系统标题栏和 VTK 生命周期。
- 按维护者本轮截图反馈，将 Ribbon 图标、两行文字和下拉指示分区，避免单 / 双行文案改变图标高度；同步公共 HTML CSS，并增加跨工具对齐断言。
- 首页显示 7 个工具，工程状态显示 18 个工具和扩展菜单；新建 / 打开连接现有对话框，任务项展示真实工程名，失败不清空已打开状态。
- 新增内置 Mono SVG 并登记清单、补中英文翻译和模块资源；图标沿用现有规范，HTML 彩色占位不替代正式单色资源规则。
- 补 QML 组件与 Shell 测试，更新模块说明与真实验证。
- 本轮按维护者要求整体评审未提交改动，优化代码与注释；不改变已确认外观，验证通过后提交完整实现。

非目标：不实现额外求解 / 导入 / 网格等工具业务，不修改 Rust 工程协议、无边框主窗口或主题 DSL；不推进旧 CI 任务，不新建 target、不换工具链。QML 不直接访问文件系统。顶部 Home / Start & Learn 的点击切换经维护者确认留待后续，本次只提交当前布局。
