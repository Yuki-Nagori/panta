## 验收标准

- [ ] 同一任务看到固定快照；修改变量创建新 revision，不污染正在运行的输入。
- [ ] 工程关闭或切换后旧任务结果被拒绝，取消和释放按顺序执行且无重复回调。
- [ ] 销毁/重建 UI 订阅不丢失应用状态、不重复启动任务；上下文不保存 JS 值或引擎对象。
- [ ] 仅持有资源引用不能获得任意写文件/启动进程能力；旧 revision 提交失败且保留当前快照。
- [ ] 代码、测试、配置和文档一致，删除废弃实现；记录真实验证并同步索引。
