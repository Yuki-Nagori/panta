## 目标与范围

在视口下方、文档页签上方增加日志区域。Plan tasks 的 Logs 和 Home Logs 单击切换面板，右上角可关闭；Logs 的勾只表示面板可见，关闭清除勾选但保留记录。日志分类复用 Tasks / Tools 的圆角页签样式，每次分析独立记录，支持选择历史运行。

## 展示组件入参

这些字段是 QML 展示入参，不是求解器协议；正式界面当前不提供示例数据。

- `ViewportPane.logRuns`：运行列表，每项包含 `id`、`contextId`、`categories` 和 `resultGroups`；运行 ID 在同一上下文内唯一。
- `ViewportPane.logContextId`：当前方案上下文，列表只显示与之匹配的记录。
- `categories`：分类列表，每项包含 `id`、`sourceText`、`text`，分类 ID 在一次运行内唯一；日志正文原样显示。
- `resultGroups`：分组列表，每项包含 `sourceText` 和 `results`。空分组标题直接显示结果项；结果项包含 `id`、`sourceText`，ID 在一次运行内跨分组唯一。
- 分类及结果标题由 QML 翻译英文 `sourceText`。选择结果只更新显示状态并报告结果 ID；临时选择按上下文和运行 ID 保留，切回历史运行时恢复。
- `ViewportPane.selectedLogRun` 向结果树提供同一个运行快照，避免运行身份与目录分别更新时错配。

## 职责评审

- 本次原生端未修改 C++ / Rust 生产代码；C++ 新增部分为 QML 组件测试夹具，无领域逻辑需要迁移。
- QML 保留显隐、分类页签、历史运行选择与当前结果勾选等临时显示状态，不创建分析记录、不解析求解器日志、不决定结果有效性。
- 正式接入时，运行生命周期、日志接收与归档、结果索引、工程关联及修订校验由 Rust 服务管理；C++ ViewModel 只适配 DTO 和 Qt 通知。当前展示入参不作为求解器协议。
- 相邻材料、Fill 和 Gate Location 确认链路已由 Rust 持有默认值、业务校验及后台写盘；C++ 的类型转换检查与确认信号属于适配职责。
